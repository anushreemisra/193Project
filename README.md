# 193Project
## Project Goal 
I'm going to make a CLI Beli for tea and coffee. This is an untargeted demographic within the restaurant industry since tea and coffee enthusiasts don't have any dedicated services for them but make up 100% of the repeat customer demographic for cafes and tea houses all over the world.

## MVP Plan
My MVP will have the following:
- Allow users to add, edit, and delete visit entries in their personal library using CLI
- Record all essential details: drink name, drink type, rating, flavor overview, review
- Save library to a local file so users always have access to their library

## Future Plans
- Let users search for entries using keywords
- Add data visualization to show progress and ratings over time
- Develop personalized recommendations based on added entries
- Adding a map showing tried places, or places of origin for coffee beans or tea leaves tried

## Tech Stack
1. Java
2. External tools/libraries:
- Scanner for reading input, but I am interested in exploring other parsing libraries 
- File I/O for saving and loading existing entries from a file
- Git/GitHub for tracking changes 
- GSON for when I use a JSON file
3. Data storage
- I’ll potentially implement a .txt file to read and update to create parsing functionality
- I’ll then explore using a JSON file for local storage
4. External data
- No external APIs or data required
- To build V2.0+ recommendations feature, only subject research will be required but no pulling data from external sources for any pipelines within the program
